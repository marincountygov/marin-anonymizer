About

Local Anonymizer changes structured data in your browser and downloads a new file. The selected file and its contents are not uploaded by this page.

Supported files

  • CSV: The first row must contain field names.
  • JSON: The top level must be an array of objects.
  • XLSX: Only the first worksheet is read. The downloaded workbook contains data only and does not preserve formulas, formatting, charts, or additional worksheets.

Anonymization actions

Hash with SHA-256
Replaces a value with a repeatable hash. Equal source values produce equal hashes.
Redact
Replaces every non-empty value with ---REDACTED---.
Synthetic value
Replaces a value with generated sample data. Repeated source values in the same field receive the same replacement during one download.

Important limitations

  • A hash is pseudonymization, not guaranteed anonymization. Common or predictable values may be guessed by comparing hashes.
  • Synthetic values do not preserve logical relationships between different fields. For example, a generated name and a generated email may not describe the same person.
  • Review the downloaded file before sharing or using it. This tool does not determine whether a dataset is legally or operationally safe to release.
  • Very large files may exceed the browser's available memory.
